# Overview

These pages provide an exhaustive reference to the various components, types, interfaces and classes that together make up VisuallyJs Angular. If you're looking for examples of how to use VisuallyJs you may wish to look through the [Learn](/angular/docs.md) area of the documentation.

note

VisuallyJs Angular has a dependency on VisuallyJs, and you will find references to various types/interfaces from the core UI throughout these reference docs. You can browse through these inline, but if you wish to take a look at the full list, head over to the [Vanilla Reference](/vanilla/docs/reference.md).

In this section of the documentation you will find:

## Components[​](#components "Direct link to Components")

This section lists out each of the Angular components in VisuallyJs, with an example usage, and, where relevant, a list of @Inputs to the component, and its class members and methods.

## Services[​](#services "Direct link to Services")

Lists the Angular services available in VisuallyJs.

## Interfaces[​](#interfaces "Direct link to Interfaces")

All of the interfaces declared by VisuallyJs Angular.
