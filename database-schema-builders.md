## Where database schema builders are used

A schema editor can be part of a database product, a developer platform, or an internal data governance workflow. It helps teams reason about how information is structured and how systems depend on it.

### Database management platforms

Give database users a visual way to create and inspect tables, views, columns, and relationships alongside their existing query and administration tools.

### Low-code application builders

Let app creators define the entities behind their applications, connect related records, and understand how changes to a data model affect the rest of the product.

### Data catalog and governance tools

Help data stewards document ownership, field meaning, and relationships across business data, making complex structures easier to review and communicate.

### ETL and data integration products

Visualize source and destination structures so integration teams can map fields, trace dependencies, and plan transformations between systems.

## What teams need from a schema builder

### Clear relational models

Show tables and views as readable entities, with columns and their types visible where users need them.

### Precise relationships

Connect individual columns to represent foreign keys and other field-level relationships, so users can follow how records relate across tables.

### Keys and constraints

Present primary keys, foreign keys, and other important column properties as part of the model, making structure easier to inspect and validate.

### Editing and inspection

Let users add tables and columns, edit names and data types, and inspect model properties without leaving the diagram.

### Readable layouts at scale

Use automatic layout, pan and zoom, and direct manipulation to keep larger schemas navigable as tables and dependencies grow.

### Interoperability with data workflows

Connect the visual model to your own persistence, SQL generation, migration, validation, or import and export workflows through an extensible application layer.

### Framework-agnostic

VisuallyJs works with React, Angular, Vue, Svelte, and TypeScript, so you can integrate a schema editor into your existing application architecture.
