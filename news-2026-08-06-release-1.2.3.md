# Release 1.2.3

August 6, 2026 ·

<!-- -->

2 min read

Release 1.2.3 is now available, with a great new plugin that places markers at the intersection of orthogonal connectors:

![Line crossings plugin](https://static.visuallyjs.com/img/blog/1.2.3/line-crossings-callflow.png)

By default, the plugin draws a bridge at each intersection, but a few different bridge types are supported.

## Bridge types[​](#bridge-types "Direct link to Bridge types")

### Arch[​](#arch "Direct link to Arch")

This is the default:

![Line crossings plugin](https://static.visuallyjs.com/img/blog/1.2.3/line-crossings.png)

### Gap[​](#gap "Direct link to Gap")

Draws a gap in one of the edges

![Line crossings plugin](https://static.visuallyjs.com/img/blog/1.2.3/line-crossings-gap.png)

### Dot[​](#dot "Direct link to Dot")

Draws a dot at the point of intersection

![Line crossings plugin](https://static.visuallyjs.com/img/blog/1.2.3/line-crossings-dot.png)

You can change the dot radius and provide your own color if you wish:

![Line crossings plugin](https://static.visuallyjs.com/img/blog/1.2.3/line-crossings-dot-custom.png)
