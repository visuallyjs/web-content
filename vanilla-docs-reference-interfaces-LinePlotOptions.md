LinePlotOptions

Options for a line chart plot

| Name       | Type                              | Description                                                                                             |
| ---------- | --------------------------------- | ------------------------------------------------------------------------------------------------------- |
| spline?    | boolean                           | If true, draw the line as a series of bezier splines, which makes for a smooth line. Defaults to false. |
| stacked?   | boolean \| "percent" \| "default" | Whether to stack series values on top of each other.                                                    |
| valueAxis? | string                            | ID of the value axis to attach to. Defaults to `DEFAULT`.                                               |
