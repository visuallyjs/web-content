BrowserUIPlugin

Defines a BrowserUI plugin

| Name                | Type                                                                                                                | Description                                                                                                                                                                                   |
| ------------------- | ------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| $edgeRedraw?        | (c:[Connection<]()[BrowserElement]()>) => any                                                                       | Optional method you can implement if you set `tracksEdgeRedraws:true`; the UI will invoke this method at the end of each edge's paint cycle. You can access the underlying edge via `c.edge`. |
| $edgeRemoved        | (edge:[Edge](), connection:[Connection<]()[BrowserElement]()>) => void                                              | Invoked when an edge has been removed                                                                                                                                                         |
| $edgeRendered       | (p:[ConnectionEstablishedParams]()) => void                                                                         | Notification that an edge was rendered                                                                                                                                                        |
| $edgeUpdated        | (edge:[Edge](), connection:[Connection<]()[BrowserElement]()>) => void                                              | Invoked when an edge has been updated                                                                                                                                                         |
| $groupCollapsed     | (element:ViewportGroupElement<[BrowserElement]()>) => any                                                           | Invoked when a group has been collapsed                                                                                                                                                       |
| $groupExpanded      | (element:ViewportGroupElement<[BrowserElement]()>) => any                                                           | Invoked when a group has been expanded                                                                                                                                                        |
| $groupMemberAdded   | (element:ViewportElement<[BrowserElement]()>) => any                                                                | Invoked when a group member has been added                                                                                                                                                    |
| $groupMemberRemoved | (element:ViewportElement<[BrowserElement]()>) => any                                                                | Invoked when a group member has been removed                                                                                                                                                  |
| $groupRemoved       | (element:ViewportGroupElement<[BrowserElement]()>) => void                                                          | Invoked when a group has been removed                                                                                                                                                         |
| $groupResized       | (params:GroupResizeResult<[BrowserElement]()>) => any                                                               | Invoked when a group has been resized                                                                                                                                                         |
| $nodeRemoved        | (element:ViewportElement<[BrowserElement]()>) => void                                                               | Invoked when a node has been removed                                                                                                                                                          |
| $vertexRerendered   | (p:{<br />  el:[BrowserElement](),<br />  id:string,<br />  size:[Size](),<br />  vertex:[Vertex]()<br />}) => void | Invoked when a vertex has been re-rendered (its type was changed and it was rerendered, which may have resulted in a different appearance)                                                    |
| $vertexResized      | (element:ViewportElement<[BrowserElement]()>, width:number, height:number) => void                                  | Invoked when a vertex has been rotated                                                                                                                                                        |
| $vertexRotated      | (element:ViewportElement<[BrowserElement]()>, rotationInDegrees:number) => void                                     | Invoked when a vertex has been resized                                                                                                                                                        |
| $vertexSynced       | (element:ViewportElement<[BrowserElement]()>) => void                                                               | Invoked when an element has been synced with the view and a repaint was requested.                                                                                                            |
| $vertexUpdated      | (element:ViewportElement<[BrowserElement]()>, reason:VertexUpdatedReason) => void                                   | Invoked when a vertex has been updated                                                                                                                                                        |
| tracksEdgeRedraws   | boolean                                                                                                             | Set this to true to inform the UI that the plugin wishes to be informed at the end of an edge paint.                                                                                          |
