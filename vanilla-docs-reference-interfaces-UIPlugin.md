UIPlugin

A plugin for the UI. You don't need to worry about this class unless you're planning on writing your own plugin.

| Name                | Type                                                                                                | Description                                                                                                                                                                                   |
| ------------------- | --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| $edgeRedraw?        | (c:[Connection\<EL>]()) => any                                                                      | Optional method you can implement if you set `tracksEdgeRedraws:true`; the UI will invoke this method at the end of each edge's paint cycle. You can access the underlying edge via `c.edge`. |
| $edgeRemoved        | (edge:[Edge](), connection:[Connection\<EL>]()) => void                                             | Invoked when an edge has been removed                                                                                                                                                         |
| $edgeRendered       | (p:[ConnectionEstablishedParams]()) => void                                                         | Notification that an edge was rendered                                                                                                                                                        |
| $edgeUpdated        | (edge:[Edge](), connection:[Connection\<EL>]()) => void                                             | Invoked when an edge has been updated                                                                                                                                                         |
| $groupCollapsed     | (element:ViewportGroupElement\<EL>) => any                                                          | Invoked when a group has been collapsed                                                                                                                                                       |
| $groupExpanded      | (element:ViewportGroupElement\<EL>) => any                                                          | Invoked when a group has been expanded                                                                                                                                                        |
| $groupMemberAdded   | (element:ViewportElement\<EL>) => any                                                               | Invoked when a group member has been added                                                                                                                                                    |
| $groupMemberRemoved | (element:ViewportElement\<EL>) => any                                                               | Invoked when a group member has been removed                                                                                                                                                  |
| $groupRemoved       | (element:ViewportGroupElement\<EL>) => void                                                         | Invoked when a group has been removed                                                                                                                                                         |
| $groupResized       | (params:GroupResizeResult\<EL>) => any                                                              | Invoked when a group has been resized                                                                                                                                                         |
| $nodeRemoved        | (element:ViewportElement\<EL>) => void                                                              | Invoked when a node has been removed                                                                                                                                                          |
| $vertexRerendered   | (p:{<br />  el:EL,<br />  id:string,<br />  size:[Size](),<br />  vertex:[Vertex]()<br />}) => void | Invoked when a vertex has been re-rendered (its type was changed and it was rerendered, which may have resulted in a different appearance)                                                    |
| $vertexResized      | (element:ViewportElement\<EL>, width:number, height:number) => void                                 | Invoked when a vertex has been rotated                                                                                                                                                        |
| $vertexRotated      | (element:ViewportElement\<EL>, rotationInDegrees:number) => void                                    | Invoked when a vertex has been resized                                                                                                                                                        |
| $vertexSynced       | (element:ViewportElement\<EL>) => void                                                              | Invoked when an element has been synced with the view and a repaint was requested.                                                                                                            |
| $vertexUpdated      | (element:ViewportElement\<EL>, reason:VertexUpdatedReason) => void                                  | Invoked when a vertex has been updated                                                                                                                                                        |
| tracksEdgeRedraws   | boolean                                                                                             | Set this to true to inform the UI that the plugin wishes to be informed at the end of an edge paint.                                                                                          |
