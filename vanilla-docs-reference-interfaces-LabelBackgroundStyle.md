LabelBackgroundStyle

Defines the style for the background of a label overlay.

| Name           | Type   | Description                                                                                                                 |
| -------------- | ------ | --------------------------------------------------------------------------------------------------------------------------- |
| fill?          | string | Fill color for the background.                                                                                              |
| opacity?       | number | Opacity for the background.                                                                                                 |
| padding?       | number | Padding to leave around the label. Defaults to 5.                                                                           |
| rx?            | number | Horizontal radius for the background rectangle's corners.                                                                   |
| ry?            | number | Vertical radius for the background rectangle's corners. If you provide `rx` but not this, `ry` will take the value of `rx`. |
| stroke?        | string | Stroke color for the background.                                                                                            |
| strokeOpacity? | number | Stroke opacity for the background.                                                                                          |
| strokeWidth?   | number | Stroke width for the background.                                                                                            |
