Geometry

Geometry defines the path along which a connector travels. The internal contents of a Geometry vary between connectors.

| Name     | Type                           | Description                                       |
| -------- | ------------------------------ | ------------------------------------------------- |
| segments | Array<[BaseGeometrySegment]()> | List of segments.                                 |
| source   | [AnchorPlacement]()            | Definition of where the edge's source is located. |
| target   | [AnchorPlacement]()            | Definition of where the edge's target is located. |
