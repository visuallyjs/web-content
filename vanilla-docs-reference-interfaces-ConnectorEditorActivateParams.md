ConnectorEditorActivateParams

Base options for activating a path editor.

| Name                  | Type                                                                                               | Description                                                                                                                                                                                                                                                                                                                                         |
| --------------------- | -------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| anchorPositionFinder? | (el:EL, elxy:[PointXY](), vertex:[Vertex]()) => [ObjectAnchorSpec]()                               | Optional function allowing you to specify the location of the placeholder when the user<br />is dragging anchor.                                                                                                                                                                                                                                    |
| anchorPositions?      | Array<[ObjectAnchorSpec]()>                                                                        | Optional array of allowed positions for anchors to be relocated to                                                                                                                                                                                                                                                                                  |
| deleteButton?         | boolean                                                                                            | If true, show a button the user can use to delete the edge. Defaults to false.                                                                                                                                                                                                                                                                      |
| deleteButtonClass?    | string                                                                                             | Classname to set on the delete button. Defaults to "vjs-edge-delete".                                                                                                                                                                                                                                                                               |
| deleteButtonLocation? | number \| Array\<number>                                                                           | Location on the path to put the delete button, as a measure of the length of the path. For instance,<br />the default value of 0.1 means the delete button will be placed at a point that is 1/10th of the total length of the path.<br />Note that you can supply an array of positions here and one delete button will be created for each entry. |
| onMaybeDelete?        | (edge:[Edge](), connection:[Connection\<EL>](), doDelete:(data:Record\<string,any>) => any) => any | Optional interceptor to invoke when the user presses the delete button. If the user wishes to go ahead<br />with the edge deletion, `doDelete` will be invoked.                                                                                                                                                                                     |
| overlays?             | Array<[FullOverlaySpec]()>                                                                         | Optional array of overlays to decorate the edge with while it is being edited.                                                                                                                                                                                                                                                                      |
