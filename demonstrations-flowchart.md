## What is a Flowchart and how can I develop one using VisuallyJs?

A flowchart is a type of diagram that represents a workflow, process or system, using various symbols and arrows. It is a visual tool for people to design and document the flow of logic.

A flowchart consists of a set of blocks connected by edges. The blocks in some flowchart can represent a wide variety of concepts. VisuallyJs ships with a set of flowchart shapes that represent many of the common concepts people want to use - things such as processes, questions, decisions, inputs, outputs, etc.

This demonstration uses a number of VisuallyJs components such as the miniview, object inspector, controls component and surface component, to provide a solid basis for an Angular, React, Vue, Svelte, Typescript or Javascript app.

## Angular Flowchart

VisuallyJs's deep Angular integration makes building an Angular Flowchart very simple. The [Angular Flowchart starter app](https://github.com/visuallyjs-angular/flowchart) uses our ControlsComponent, DiagramComponent, MiniviewComponent and Angular service to provide a fully featured Flowchart.

## React Flowchart

React Flowcharts with VisuallyJs are a snap. Our [React Flowchart starter app](https://github.com/visuallyjs-react/flowchart) uses VisuallyJs's advanced React integration with its providers and support for functional components, to give you a solid foundation on which to base your app.

## Vue Flowchart

It's easy to build a Vue Flowchart diagram with VisuallyJs - we've done most of the hard work for you in our [Vue Flowchart starter app.](https://github.com/visuallyjs-vue/flowchart)

Our Vue Flowchart takes advantage of VisuallyJs's ability to integrate deeply with Vue, using Vue components to render nodes, and several of VisuallyJs's Vue helper components and plugins such as the ControlsComponent, MiniviewComponent, DiagramComponent, GeneratedGridBackground plugin, Lasso plugin, and more. With VisuallyJs's Vue Flowchart all you need to do is drop it into your app and off you go.

## Svelte Flowchart

VisuallyJs's Svelte integration has everything you need to quickly build a Svelte Flowchart, and what's great is we've already pulled it all together for you in our [Svelte Flowchart builder starter app.](https://github.com/visuallyjs-svelte/flowchart)

Our Svelte Flowchart uses several of VisuallyJs's Svelte components, including the DiagramComponent, ControlsComponent and MiniviewComponent, and it also takes advantage of our SurfaceProvider, which works like a provider in React - use it to enclose several child components and a shared context is established, allowing all of the component to access a single dataset without the need for manually plugging them all together.
