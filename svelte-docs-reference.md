# Overview

These pages provide an exhaustive reference to the various components, providers, props, interfaces and classes that together make up VisuallyJs Svelte. If you're looking for examples of how to use VisuallyJs you may wish to look through the [Learn](/svelte/docs.md) area of the documentation.

note

VisuallyJs Svelte has a dependency on VisuallyJs, and you will find references to various types/interfaces from the core UI throughout these reference docs. You can browse through these inline, but if you wish to take a look at the full list, head over to the [Vanilla Reference](/vanilla/docs/reference.md).
