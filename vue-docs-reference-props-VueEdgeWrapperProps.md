VueEdgeWrapperProps

The props that are passed in to a component used to render an overlay by a surface or paper component.

| Name    | Type                        | Description                           |
| ------- | --------------------------- | ------------------------------------- |
| data    | [ObjectData]()              | Data that backs the object. Reactive. |
| def     | any                         | Definition for this node/group type   |
| edge    | [Edge]()                    | The edge that is being rendered.      |
| el      | [BrowserElement]()          | The underlying DOM element            |
| model   | [BrowserUIModel]()          | Underlying model.                     |
| obj     | [Edge]()                    | The edge that is being rendered       |
| overlay | Overlay<[BrowserElement]()> | The overlay that is being rendered.   |
| ui      | [BrowserUI]()               | Underlying UI                         |
