# Features

VisuallyJs has an extensive feature set to allow you to rapidly build diagrams, charts, node-based UIs with rich graphical content and dashboards.

Library Integrations

Angular

![](https://static.visuallyjs.com/img/features/angular_300.png)

All versions of Angular from 18+

React

![](https://static.visuallyjs.com/img/features/react_300.png)

All versions of React from 16+

Vue

![](https://static.visuallyjs.com/img/features/vue_300.png)

Vue 3 Integration

Svelte

![](https://static.visuallyjs.com/img/features/svelte_300.png)

Svelte 5 Integration

Components

Surface

![](https://static.visuallyjs.com/img/features/surface_300.png)

Infinite panning, smooth as butter zoom

Node palette

![](https://static.visuallyjs.com/img/features/node-palette_300.png)

Drag/drop new nodes and groups

Shape Libraries

![](https://static.visuallyjs.com/img/features/shape-library_300.png)

Render your nodes as SVG shapes

Controls

![](https://static.visuallyjs.com/img/features/controls_300.png)

Zoom to fit, undo/redo etc

Dialogs

![](https://static.visuallyjs.com/img/features/dialogs_300.png)

Data-bound dialogs for editing

Inspector

![](https://static.visuallyjs.com/img/features/inspector_300.png)

Data-bound inspector for editing

Element Dragger

![](https://static.visuallyjs.com/img/features/element-dragger_300.png)

Make external elements draggable

CSS

![](https://static.visuallyjs.com/img/features/css_300.png)

Fully customizable via CSS

Plugins

Miniview

![](https://static.visuallyjs.com/img/plugins/miniview-500.png)

A miniaturized view of your canvas. Pan/zoom via the miniview, and click to scroll

Lasso

![](https://static.visuallyjs.com/img/plugins/lasso-500.png)

Snag a set of nodes and add them to the model's current selection.

Resize Tools

![](https://static.visuallyjs.com/img/plugins/resize-500.png)

Grow, shrink and rotate vertices, either with visible handles or via the vertex edges

Backgrounds

![](https://static.visuallyjs.com/img/plugins/background-500.png)

Grids - with dots or lines - and tiled or static images

Controls

![](https://static.visuallyjs.com/img/plugins/controls-500.png)

Buttons for common operations such as zoom to extents, undo/redo, etc

Edge Crossings

![](https://static.visuallyjs.com/img/plugins/line-crossings-500.png)

Mark the intersection of two edges with a bridge or a dot

Drawing

![](https://static.visuallyjs.com/img/plugins/vertex-drawing-500.png)

Draw new nodes/groups by dragging the mouse

Snaplines

![](https://static.visuallyjs.com/img/plugins/snaplines-500.png)

Visual cues to help align everything just so

Value Propagation

![](https://static.visuallyjs.com/img/plugins/graph-propagation-500.png)

Automatically propagate values through the graph with a declarative API

Pan Buttons

![](https://static.visuallyjs.com/img/plugins/panbuttons-500.png)

Click to nudge the canvas, or hold to scroll

Scrolling Lists

![](https://static.visuallyjs.com/img/plugins/scrolling-lists-500.png)

Automatically park edges on their container when the source/target element is scrolled out of view

and many more...

Layouts

Layouts

![](https://static.visuallyjs.com/img/features/layouts_300.png)

Force Directed, Hierarchy, Balloon, Circular, or write your own

Custom Layouts

![](https://static.visuallyjs.com/img/features/custom-layout_300.png)

Writing your own layout is a snap

Magnetizer

![](https://static.visuallyjs.com/img/features/magnetizer_300.png)

Easily avoid overlapping nodes

Data Model

Graph Operations

![](https://static.visuallyjs.com/img/features/graph_300.png)

Interact deeply with your data model

Undo & Redo

![](https://static.visuallyjs.com/img/features/undo-redo_300.png)

On every model operation

Transactions

![](https://static.visuallyjs.com/img/features/transactions_300.png)

Batch multiple operations

Paths

![](https://static.visuallyjs.com/img/features/paths_300.png)

Show/animate paths between elements

Selections

![](https://static.visuallyjs.com/img/features/selections_300.png)

Operate on parts of the dataset in isolation

Full text search

![](https://static.visuallyjs.com/img/features/text-index_300.png)

Inverted text search index

Copy & paste

![](https://static.visuallyjs.com/img/features/copy-paste_300.png)

Copy/paste nodes, groups and edges
