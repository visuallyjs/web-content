PanZoomEventPayload

Payload for a pan/zoom event from a surface.

| Name    | Type   | Description                             |
| ------- | ------ | --------------------------------------- |
| event?  | Event  | Event that caused the pan. May be null. |
| oldZoom | number | previous zoom                           |
| x       | number | Current x pan value                     |
| y       | number | Current y pan value                     |
| zoom    | number | current zoom                            |
