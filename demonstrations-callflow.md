## What is a Callflow Builder and how can I develop one using VisuallyJs?

A Callflow Builder is a visual tool that allows users to design and manage the flow of automated calls or interactive voice response (IVR) systems. Similar to a chatbot builder, it uses a graphical interface to define the sequence of actions, decisions, and interactions within a phone call. This can include routing calls, playing audio prompts, collecting user input, and integrating with other systems.

VisuallyJs is an excellent choice for creating a Callflow Builder - its deep integration with the leading UI frameworks make it a snap to create components with rich interactive features, and simple yet powerful declarative approach to configuring connectivity mean you can just focus on what makes your app different.

## Angular Callflow

VisuallyJs's deep Angular integration makes building an Angular Callflow very simple. The [Callflow starter app](https://github.com/visuallyjs-angular/callflow) uses our ControlsComponent, SurfaceComponent, MiniviewComponent and Angular service to provide a fully featured app you can use to kick start your own.

## React Callflow

React Callflows with VisuallyJs are a snap. Our [React Callflow starter app](https://github.com/visuallyjs-react/callflow) uses VisuallyJs's advanced React integration with its providers and support for functional components, to give you a solid foundation on which to base your app.

## Vue Callflow

It's easy to build a Vue Callflow with VisuallyJs - we've done most of the hard work for you in our [Vue Callflow starter app.](https://github.com/visuallyjs-vue/callflow)

Our Vue Callflow takes advantage of VisuallyJs's ability to integrate deeply with Vue, using Vue components to render nodes, and several of VisuallyJs's Vue helper components and plugins such as the ControlsComponent, MiniviewComponent, SurfaceComponent, GeneratedGridBackground plugin, Lasso plugin, and more. With VisuallyJs's Vue Callflow all you need to do is drop it into your app and off you go.

## Svelte Callflow

VisuallyJs's Svelte integration has everything you need to quickly build a Svelte Callflow, and what's great is we've already pulled it all together for you in our [Svelte Callflow builder starter app.](https://github.com/visuallyjs-svelte/callflow)

Our Svelte Callflow uses several of VisuallyJs's Svelte components, including the SurfaceComponent, ControlsComponent and MiniviewComponent, and it also takes advantage of our SurfaceProvider, which works like a provider in React - use it to enclose several child components and a shared context is established, allowing all of the component to access a single dataset without the need for manually plugging them all together.
