BaseGeometrySegment

Base segment in an edge geometry.

| Name | Type   | Description                            |
| ---- | ------ | -------------------------------------- |
| x1   | number | X location of first point in segment.  |
| x2   | number | X location of second point in segment. |
| y1   | number | Y location of first point in segment.  |
| y2   | number | Y location of second point in segment. |
